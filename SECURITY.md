# Security Policy

## What this project does

`Un-PreCompose.jsx` is an After Effects script that only manipulates layers in the open project. It does not read or write files, access the network, run shell commands, or evaluate dynamic code, so it works with After Effects' **Allow Scripts to Write Files and Access Network** setting turned off.

There is no installer: you run the script directly or copy it into After Effects' `Scripts` folder yourself.

## Verify what you install

Only download this project from its GitHub repository, and read the files before running them. The script is plain text with no binaries, dependencies or obfuscated code.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** button on the repository's **Security** tab (private vulnerability reporting), rather than opening a public issue. Include the After Effects version, operating system, and steps to reproduce.
